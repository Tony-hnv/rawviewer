# RAW View 品牌 Logo 资源

本目录中的 PNG 是从 [Simple Icons](https://github.com/simple-icons/simple-icons) 公开 SVG 图标转换而来，用于 RAW View 的**品牌识别**功能。图片保留各品牌的实际 Logo 轮廓，并以透明白色遮罩保存，使界面和导出边框能按主题前景色显示。

图标源仓库以 CC0 1.0 发布；各商标仍归其各自权利人所有。RAW View 不隶属、未获各品牌背书，Logo 仅用于说明可选的品牌信息。

如需重新生成资源，请在项目根目录运行：

```bash
python3 scripts/build_brand_logos.py
```
